# Phone-ST — форк Grecha (v2)

## Что нового относительно Phone-ST-Grecha-music.zip

### Подключение телефона
- **Свой профиль работает независимо от чата.** Раньше телефон ловил «unauthorized», если чат стоял на другом профиле: сервер таверны брал активный ключ источника, а не ключ профиля. Теперь перед запросом активный секрет переключается на профильный и возвращается обратно.
- **Поле «Свой ключ API для телефона»** в настройках (под выбором профиля). Введён — запросы идут напрямую к провайдеру профиля, минуя сейф таверны: чат и телефон работают одновременно без переключений. Пусто — старый путь с переключением секрета. Работает для профилей с URL (custom/прокси); запросы с картинкой и гугловые профили — по-старому.

### Музыка
- **Вкладка настроек (шестерёнка)** в музыке. Туда переехали тогглы источников и API-ключи из панели поиска.
- **Предпочтения для ✨-подбора под сцену**: голос — «Любое / Со словами / Без слов»; язык — «Любой / На русском / На английском / Другие». Влияют только на ✨-подбор, ручной поиск как был.
- **Мини-кнопка пуск/пауза под плавающей кнопкой телефона** — появляется, когда есть текущий трек; музыкой можно рулить, не открывая телефон. Следует за кнопкой при перетаскивании.

### Из старого зипа (для справки)
Поиск по категориям магазина с ✨-генерацией товаров, фикс двойного списания в банке, фикс зависания доставки, музыка (NetEase/GDStudio, Jamendo, YouTube с проверкой встраивания, радио SomaFM + поиск станций, ✨-подбор под сцену).

## Установка
Распаковать в `SillyTavern/public/scripts/extensions/third-party/` (папка `Phone-ST`, поверх старой — согласиться на замену), затем Ctrl+F5 в браузере.

Termux: `cd ~/Silly*/public/scripts/ext*/third-party && python3 -m zipfile -e /sdcard/Download/Telegram/Phone*.zip .`
